# Capstone
##Capstone project for MLAI course
###The research question you intend to answer (in one sentence, if possible)
-Can ML be used to predict what kind of therapies would work best against certain mental health diagnoses?
Your expected data source(s) (as either a link to existing data or a sentence describing where you will source the data from)
https://www.kaggle.com/datasets/uom190346a/mental-health-diagnosis-and-treatment-monitoring/dataLinks to an external site.

###The techniques you expect to use in your analysis
-Will be using KNN, Decision Trees and Random Forests, Logistic Regression and SVM. Will then compare these against each other. 

###The expected results:
Expecting results as training and testing scores along with average fit speeds. 

###Why this question is important:

This question is important because current mental health treatment assignments are done with a trial-and-error process. People are prescribed a certain treatment that may or may not alleviate their condition and in some cases may even worsen symptoms. The hope is that ML can be used to identify which therapies might be best for certain people so that there is less risk of more severe disease before finding the right treatment.
